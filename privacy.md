# Privacy Policy

drive-oauth is a personal tool used only by its owner (ktwu1997) to access his own Google Drive.

Data accessed: files in the owner's own Google Drive, through the Google Drive API.

How it is used: only to read, write and manage the owner's own files on the owner's own computer.

Sharing: no data is collected from, shared with, sold to or transferred to any third party.

Storage: OAuth tokens are stored only on the owner's own machine. No server stores user data.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
